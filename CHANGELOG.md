### Docs

- **Reorganized the docs tree** for a flat, current set:
  - `docs/spec.md` (was `docs/architecture/spec.md`)
  - `docs/frontend-styleguide.md` (was `docs/styleguide.md` → `docs/design/frontend-styleguide.md`)
  - `docs/api-notes.md` (was `docs/integrations/api-notes.md`)
  - `docs/dev-plan.md` (was `docs/operations/dev-plan.md`)
  - `docs/images/` (was `docs/assets/images/`)
- **Deleted the unmaintained wireframe artboards** and the auto-generated
  `record-collection-wireframe.html`. The 3 `.dc.html` artboards and the
  `canvas.json` index were last touched in the initial commit and referenced a
  `support.js` that was never committed; the rendered HTML is regenerated by
  an external design tool. The `docs/wireframe/` and `docs/archive/wireframe/`
  directories are gone.
- **Standardized YAML frontmatter** across the doc corpus (`title`, `last_updated`,
  `status`, `scope`, `audience`, `tags`).
- **`docs/api-notes.md` and `docs/dev-plan.md` are now `status: current`**, not
  archived — `api-notes.md` is the implementation reference for the Discogs,
  OpenRouter, and Brother QL integrations, and `dev-plan.md` carries the
  "What's left" operational follow-ups.
- **`docs/spec.md`** — two content fixes: the OpenRouter section now says the
  key is "gated on" (not "required"), and "paid prices" is renamed to
  "purchase prices" to match the README.
- **README** — development-section cross-links updated to the new flat paths,
  plus pointers to this `CHANGELOG.md` and `CONTRIBUTING.md`.
- **Added** `CHANGELOG.md` (this file) and `CONTRIBUTING.md` at the repo root.

### Features (since the last docs pass)

- `records backup` / `records restore` for purchase prices and folder colors.
- PDF label output (`--pdf out.pdf`) with `settings.yaml` media configuration.
- `--divider all` batch printing of every folder divider.
- `crate` view: flip through dividers and albums record-store style
  (`/crate` route, `lib/static/crate.js`).
- OpenRouter key is now optional — without one, the app works normally and AI
  actions report themselves disabled.
- `pytest` suite covering labels, sync, and the web API.

## 2026-08-22 — Initial commit

- Discogs collection mirror (folders, items, custom fields) into a local SQLite
  database, with throttling + pagination.
- Web app for browsing, drag-and-drop folder moves, and item detail editing
  (writes straight back to Discogs).
- Pillow-rendered sleeve and divider labels on a Brother QL label printer
  (USB via `brother-ql-next`).
- AI assist: Style + Summary drafts, folder suggestions.
- MIT license, README, screenshot-led feature tour.
